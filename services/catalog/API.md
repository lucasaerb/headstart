# Read API, version1

Run the root setup in `docs/architecture/development.md`. The loopback server provides `GET /v1/search`, `GET /v1/projects/{id}`, `GET /v1/components/{id}/versions/{version}`, plus `/api/catalog/search` as an alias. Retrieval is public metadata, no source-content delivery, identity gate bypass, target mutation or royalty claim. Only published scoped project versions and eligible component versions enter this index; the seed is2048's Tile state primitive, not a reviewed complete game.

Search accepts `q` (max200characters), `runtime`, `runtime_version` (requires runtime; only exact tested support matches), `platform`, `rights`, `readiness`, `type=project|component`, `limit`1–100(default24), and signed opaque `cursor`. Filters intersect before lexical ranking. Unknown compatibility cannot satisfy support. Exact title/repository/alias and token/source-path matches explain themselves in `matchReasons`; no semantic model or embeddings are used. Stable ordering uses score, identity and version. Parent project identity groups components and versions. Version/index/filter-bound cache keys are returned; HTTP caching is intentionally no-store in the local server.

`GET /api/research` serves the explicitly separate persisted display projection with `eligibility=research_only`; its API version is `headstart-research-api-1`. It accepts `q,genre,capability,runtime,style,platform,kind,model,sort,limit,cursor`. Facets are exact values from the returned `facets`. Sort is `recommended|stars`, stars are dated repository observations with unknown ranked last. `ids` is a comma-separated selection of at most3IDs, mutually exclusive with filters/cursor, for bag metadata lookup. UI layout is not a server filter. Metadata image references retain their rights status; pending rights never become reviewed through this endpoint.

Responses include `items,total,nextCursor,appliedFilters,facets,indexVersion,cacheKey`. Errors use `{error:{code,message,retriable,action}}`:400 malformed/unknown/duplicate query or cursor;404 no eligible version;409 cursor invalidated by index change;422 unsupported combination;503 missing local catalog/interpreter/storage. Cursors cannot change query or page size and reject tampering. Restart search after409. All methods other than GET return405; no mutation endpoint is exposed.

The persistence and API are local-only. Python subprocess requests are bounded by URL length,10second timeout and4MB response size; child stderr is not forwarded to visitors. Cursor keys stay local with restrictive permissions. Initialize/refresh is a deliberate command, never a visitor-triggered import. A live Vercel API requires a separately reviewed hosting adapter.
