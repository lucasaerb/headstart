# Export a HeadStart Gauntlet Loop from the selected bag

Replace the bag's disconnected-Astra/JSON-notes dead end with a useful Markdown prompt that can be copied or downloaded.

Acceptance:
- Selected one-to-three games and an optional detailed brief survive export; closed-source projects remain inspiration only, with no invented repository or source revision.
- The prompt starts the agent with “What would you like to build?” and elicits detailed gameplay, per-game contribution, style, platform, runtime, input, scope and success criteria.
- Before implementation, request existing visual references, generate explicitly labeled concept mockups, and get the user's choice/refinements. Generated mockups must not be represented as actual implemented-game screenshots.
- After the brief/design stage, instruct a builder and an independent reviewer to build, exercise actual gameplay/E2E, capture real screenshots, compare the selected mockups, fix findings and repeat until PASS; unavailable tools and failed checks remain visible.
- Metadata-only planning remains distinct from protected platform source export/reuse handoff, which still requires verified identity and scoped rights. Selection is not evidence of actual reuse or royalty terms.
- “Continue with Astra” builds and copies the prompt while opening `https://chatgpt.com/` from the same user gesture. Markdown download, preview/manual-copy, direct-link fallback, empty state, removal, persistence and the 4,000-character brief work on desktop/mobile. The UI states that the user must paste the prompt and does not imply prompt prefill, automatic bag sync or a live bag connection.
- Independent reviewer checks prompt content, malformed metadata, tests, actual UI interactions and screenshots; repeat fixes until PASS.

This is a self-contained prompt workflow named Gauntlet Loop, not a claim that a separate loop skill or hosted executor is installed. Existing local collection storage is retained. No image generation or game integration runs inside the catalog.

Status: independent PASS; [review and browser evidence](../reviews/gauntlet-prompt/REVIEW.md).
