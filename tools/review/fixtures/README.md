# First-party expert review fixture

Synthetic product brief: a quiet coastal garden, muted sage/blue/ochre colors, rounded readable silhouettes, matte surfaces and restrained movement. This fixture is separate from HeadStart's C4 site and uses only authored canvas shapes and toy kinematics.

Deliberate bad claims/defects in before.mjs: an unrequested neon spiked tower, a second simulation owner despite an existing world, and an event callback that survives disposal. The unverified marketing claim “this runs at 120 FPS and is twice as fast” has no workload, device, samples or source. It must be rejected as unmeasured, not copied into a BenchmarkRun.

The after.mjs file is an explicitly bounded reference correction for the fixture only. Tests apply it into a temporary selected project and preserve unrelated files. No upstream game integration or user project is modified. Performance measurements, if collected, are CPU-only toy-update batches and cannot prove gameplay frame time or broad speedup.
