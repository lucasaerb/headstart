# HeadStart mockup library

Open `http://127.0.0.1:8765/mockup-library/dist/` while the package server is running:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory HeadStart-Starter-Package
```

Buildless HTML/CSS/JavaScript. The gallery supports family filters, search, full-image viewing and two-image comparison. It references existing originals without changing them. Add new images to `dist/data.js`. Image mockups depict proposed behavior, not running product services.

The final C storyboard is available at `http://127.0.0.1:8765/design-explorations/2026-09-simplicity/FINAL-STORYBOARD.html`.
