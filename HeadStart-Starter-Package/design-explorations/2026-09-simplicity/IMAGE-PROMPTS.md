# HeadStart concept generation

Built-in image generation tool; three independent new concept boards. Generated artwork and fictional game examples, not screenshots or verified catalog entries.

## A

Use case: ui-mockup. Create a polished high-resolution product design storyboard presentation image for HeadStart, a curated library of playable open-source games and reusable game systems. User brief: simplicity is key, purpose instantly clear, engaging game images that demonstrate gameplay. NOT a dashboard, not an AI chat app, not a game generator. This is a static design concept. Use fictional game examples only, no real repository names or fake verified badges, licenses, performance stats, install success. Each artwork has a small legible "Concept preview" caption. White/light interface surfaces, dark readable type, blue actions. No sidebar, account avatar, social metrics, pricing, complex filters or decoration. Use beautifully typeset very legible English. Board layout: landscape 3:2 around 3000x2000 or highest suitable resolution. Top: compact design direction title outside app. Main upper area: ONE LARGE desktop landing screen at left about 78% width and ONE NARROW mobile landing screen at right about 20% width. Lower area: TWO smaller desktop flow screens side by side with short storyboard captions outside the frames. The upper desktop is step 1, lower-left step 2, lower-right step 3, phone is mobile step 1. Frames are flat orthographic UI designs, no perspective devices. Consistent UI and images across steps. At bottom outside UI include "Design study · Fictional examples · Generated artwork · No live demo or agent connection". Main priority visual restraint, genuinely different composition from standard SaaS templates. Do not add extra sections or copy beyond requested. Direction A title: "A / Find your starting point". Top app nav only HeadStart on left and "Explore" / "How it works" right. Step 1 main heading "A head start for your next game." Supporting sentence "Find open-source games. Play them. Build on the parts you like." Wide simple search field "What do you want to build?" with blue "Find a starting point" button.
