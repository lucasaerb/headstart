# Ontology v0.1

Keep independent facets for content kind, genre, capability, dimension, perspective, visual style, runtime, language, physics, input, platform, authoring tools and rights/readiness. Map ordinary language to canonical concepts while preserving explicit user constraints.

Initial concept examples: camera.chase, camera.first_person, movement.character, movement.flight, movement.driving, physics.vehicle, physics.rigid_body, world.terrain, world.geospatial, world.streaming, generation.dungeon, generation.seeded, rendering.shader, rendering.particles, system.inventory, system.combat, system.multiplayer, ui.hud.

Blender is an authoring tool. R3F is a React rendering layer over Three.js. A visual vehicle model is not vehicle physics. A genre or art-style match is not a target compatibility guarantee. A world demo does not automatically contain traffic, missions or multiplayer.

Readiness is suggested, source_reviewed, isolated or integration_tested. Demo health, source-to-demo relation, rights and readiness are independent. Every tested claim must identify its evidence and version scope.
